# ELITEMARKET

Premium digital-goods marketplace — **dark elite / gold** design (not Etherealmarket).

## Stack
React · TypeScript · Vite · Tailwind CSS

## Features
- Login / Register
- Catalog (~3000 unique listings)
- Filters: country, brand, type, level, bank, BIN search, ZIP search
- Cart + checkout (balance or crypto)
- Deposit with TXID
- Orders, My Cards, Support, Account
- Admin: cards, orders, deposits, users, wallets

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Netlify
Connect this repo (`Elitemarket`). Build: `npm run build`. Publish: `dist`.
SPA redirects included via `netlify.toml` and `public/_redirects`.

## Design
Black background · gold accents · horizontal listing rows · mobile bottom nav · centered ELITE header
